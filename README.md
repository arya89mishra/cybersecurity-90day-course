## 📖 Key Topics Summary

### Week 1-2: Fundamentals
**Cybersecurity Basics:**
- CIA Triad: Confidentiality (privacy), Integrity (accuracy), Availability (access)
- Threat: potential danger
- Vulnerability: weakness that can be exploited
- Risk: probability of threat exploiting vulnerability

**Networking:**
- OSI Model: 7 layers from physical to application
- TCP/IP: Internet protocol suite
- Ports: 0-65535, common ports like 80 (HTTP), 443 (HTTPS), 22 (SSH)

**Linux:**
- Root = administrator
- File permissions: rwx (read, write, execute)
- sudo = run as administrator
- Common commands: ls, cd, cat, grep, chmod

---

### Week 3-4: Tools & Web
**Networking Tools:**
- ping: Test connectivity
- nslookup/dig: DNS queries
- netstat: Network connections
- curl: Download files, send requests
- Nmap: Port scanning and service enumeration

**Web Basics:**
- HTTP: Hypertext Transfer Protocol (port 80)
- HTTPS: HTTP + TLS encryption (port 443)
- GET: Request data
- POST: Send data
- Cookies: Store client info
- Sessions: Track user activity

---

### Week 5-6: Advanced Tools
**Nmap Scanning:**
- -sS: SYN scan (stealthy)
- -sT: TCP connect scan
- -sU: UDP scan
- -p: Specify ports
- -A: Aggressive scan

**Wireshark:**
- Packet capture and analysis
- Apply filters
- Analyze protocols (TCP, UDP, DNS, HTTP)
- Track conversations

---

### Week 7-8: Web Security
**OWASP Top 10:**
1. SQL Injection: Insert malicious SQL
2. XSS: Inject JavaScript
3. CSRF: Force user actions
4. Broken authentication
5. Sensitive data exposure
6. XML external entities
7. Broken access control
8. Security misconfiguration
9. Using components with known vulnerabilities
10. Insufficient logging & monitoring

**Burp Suite:**
- Intercept: Capture and modify requests
- Repeater: Re-send requests
- Scanner: Automated vulnerability scanning
- Intruder: Brute force and fuzzing

---

### Week 9: Cryptography
**Encryption Types:**
- Symmetric: Same key for encrypt/decrypt (AES, DES)
- Asymmetric: Public/private key pair (RSA)

**Hashing:**
- MD5: Fast but not secure (deprecated)
- SHA-1: Still used but weak
- SHA-256: Strong (recommended)

**TLS/SSL:**
- Secures data in transit
- Uses certificates
- Port 443

---

### Week 10: Defense
**Firewalls:**
- Block/allow traffic based on rules
- Stateful: Track connections
- Stateless: Packet-by-packet

**IDS/IPS:**
- IDS: Detect intrusions (alert)
- IPS: Prevent intrusions (block)

**SIEM:**
- Log aggregation and analysis
- Detect anomalies
- Alert on threats
